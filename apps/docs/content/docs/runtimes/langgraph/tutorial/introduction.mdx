In this tutorial, we will build a stockbroker assistant using LangChain.js, LangGraph.js and openagentui.

We will go through the necessary steps to integrate openagentui with a LangGraph Cloud endpoint.
Code snippets focus on the setup of the frontend, but we will highlight relevant sections of the backend code as well.

This agent uses the following features:

- Streaming of messages from LangGraph state to openagentui
- Rich text rendering using Markdown
- Generative UI: Mapping tool calls to tool UIs
- Approval UI: Confirming tool calls before execution (human-in-the-loop)

## Prerequisites

- Node.js 24 or higher

- Demo: https://openagentui-stockbroker.vercel.app/
